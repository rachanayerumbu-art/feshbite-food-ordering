# 🍕 FreshBite - Online Food Ordering Website

FreshBite is a modern and responsive online food ordering web application developed using **HTML, CSS, and JavaScript**.  
The project provides a complete food ordering experience where users can browse restaurants, explore menus, add items to cart, apply coupons, place orders, and track order status.

This project was developed as part of the **Data Alcott Systems Web Development Internship**.

---

## 🚀 Features

### 🏠 User Interface
- Modern responsive food delivery landing page
- Attractive hero section with search functionality
- Restaurant and menu sections
- Mobile-friendly navigation
- Smooth scrolling and animations

### 🍽️ Food Menu System
- Display multiple food items
- Food categories
- Veg / Non-Veg filtering
- Gluten-free filtering
- Food details popup with:
  - Description
  - Ingredients
  - Nutrition information
  - Price

### 🏪 Restaurant Features
- Restaurant listing
- Cuisine filtering
- Rating filtering
- Price range filtering
- View restaurant menu

### 🛒 Shopping Cart
- Add food items to cart
- Increase/decrease quantity
- Remove items automatically when quantity becomes zero
- Cart drawer interface
- Dynamic price calculation 

### 🎟️ Coupon System
Supported coupons:

- `FRESH20` → 20% discount
- `SAVE50` → ₹50 discount

### 👤 User Account System
- User registration
- User login
- Profile display
- Logout functionality
- Multiple user storage using Local Storage

### ❤️ Wishlist
- Add items to wishlist
- Remove wishlist items
- Save wishlist permanently using Local Storage

### 📦 Checkout & Order Tracking
- Delivery address input
- Phone number validation
- Delivery time selection
- Payment options:
  - Cash On Delivery
  - UPI
  - Credit/Debit Card
- Generate unique order ID
- Order confirmation tracking
- Order history management
- Delete previous orders

### 📞 Contact Section
- Customer contact form
- Contact information display
